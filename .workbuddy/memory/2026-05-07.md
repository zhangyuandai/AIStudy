## Node.js 后端服务搭建完成

用户确认推进商用，要求搭建数据库设计 + Node.js 脚手架。已在 `server/` 目录下创建完整后端项目：

### 交付物
- **数据库**: 10张表完整Schema（`database/schema.sql`），含初始配置数据
- **Node.js项目**: Express 4 + MySQL 8.0 + JWT认证
- **41个API端点**: 完整覆盖 认证/用户/积分/商城/订单/店员/管理后台
- **7个Service层模块**: userService, pointsService, giftService, orderService, checkinService, staffService, configService
- **中间件**: JWT双Token(user/admin), Joi参数校验, 全局错误处理, Rate Limiting
- **部署方案**: Dockerfile(多阶段构建) + docker-compose.yml(MySQL+API+Nginx) + nginx.conf
- **核心事务安全**: 签到防重复(UNIQUE约束), 积分扣减(FOR UPDATE行锁), 兑换(完整事务链)

### 技术要点
- Joi v17 不支持 `.integer()` 方法 → 已改为 `.number()` 类型校验
- mysql2/pool 的 acquireTimeout/timeout 参数在连接池级别不支持（仅connection级）→ 已移除
- 微信登录当前为开发模拟模式（直接返回mock openid），生产需替换为真实code2Session调用
- 默认管理账号: admin/admin123（部署时自动初始化）
